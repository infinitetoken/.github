# Security Policy

## Reporting a Vulnerability

If you find a security problem in any Infinite Token project, including Lumber, its client libraries and the `lumber` command, email **security@infinitetoken.com** with what you found and how to reproduce it.

Please don't open a public issue for it, and give us time to fix it before telling anyone else.

## Supported Versions

Fixes go into the latest release of each project. Older versions don't get fixes backported, so update to the latest.

## Lumber's Encryption

What Lumber encrypts, and what its servers can and can't see, is on [Lumber's Security page](https://lumber.infinitetoken.com/security) and in its [encryption docs](https://lumber.infinitetoken.com/docs/encryption).
