# Infinite Token

Software from Lincoln, Nebraska, since 2010. Private by default: Lumber can't read your logs, SlingScan sends scans straight over your own Wi-Fi, and [our games](https://games.infinitetoken.com) have no ads, accounts or tracking.

## Lumber

[Lumber](https://lumber.infinitetoken.com) is end-to-end encrypted logging. Your servers encrypt every log before it's sent, Lumber's servers keep only ciphertext, and you read your logs in Lumber's apps for iPhone, iPad, Mac, Windows and Linux, or let your AI agent read them over MCP, decrypted on your own computer.

| Language | Client |
| --- | --- |
| Node.js | [Lumber-Node](https://github.com/infinitetoken/Lumber-Node) |
| Python | [Lumber-Python](https://github.com/infinitetoken/Lumber-Python) |
| Go | [lumber-go](https://github.com/infinitetoken/lumber-go) |
| Java and Kotlin | [Lumber-Java](https://github.com/infinitetoken/Lumber-Java) |
| C# and .NET | [Lumber-DotNet](https://github.com/infinitetoken/Lumber-DotNet) |
| PHP | [Lumber-PHP](https://github.com/infinitetoken/Lumber-PHP) |
| Terminal and MCP | [Lumber-CLI](https://github.com/infinitetoken/Lumber-CLI), the `lumber` command and its MCP server |

The clients are open source under the MIT License, so you can check that your logs are encrypted before they leave your servers.

## SlingScan

[SlingScan](https://slingscan.infinitetoken.com) turns your iPhone into a wireless barcode scanner for your Mac or Linux computer: every code you scan is typed into the app in front. The desktop downloads are in [SlingScan-Releases](https://github.com/infinitetoken/SlingScan-Releases).
